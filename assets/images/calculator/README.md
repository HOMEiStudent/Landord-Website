# Calculator images

Drop the methodology flowchart here.

**Exact filename required:** `how-it-works-flowchart.png`
(all lowercase — GitHub Pages is case-sensitive)

- Format: PNG or SVG, about 1200px wide
- Style: HOMEi orange brand palette
- Compress to under ~200 KB (squoosh.app works well)

The methodology page (`how-the-calculator-works.html`) already points at this
file. As soon as it is uploaded with the exact name above, it appears on the
page automatically. Until then, a styled placeholder shows instead, so the
page never looks broken.

## How to upload on GitHub
1. Open this folder (`assets/images/calculator/`) on GitHub
2. Add file → Upload files
3. Drag in the PNG named `how-it-works-flowchart.png`
4. Commit to the branch
